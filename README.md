Basics Codelab Android App

This project is a beginner Android application developed using Kotlin and Jetpack Compose as part of learning modern Android UI development.

 Features

* Onboarding screen
* Dynamic greetings list using LazyColumn
* Expandable and collapsible cards
* Smooth UI animations
* Material 3 theming
* Dark mode support
* State management with `rememberSaveable`

Technologies Used

* Kotlin
* Jetpack Compose
* Android Studio

Concepts Practiced

* Composable functions
* State and recomposition
* UI theming and typography
* Animations in Compose
* Responsive layouts
* Accessibility basics
* String resources

Purpose

The purpose of this project was to practice and understand the fundamentals of Jetpack Compose and modern Android application development.

Author

Developed as part of Android development practice and industrial attachment learning.
